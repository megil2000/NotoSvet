# НотоСвет — «Падающие ноты»

Программа для ПК из плана проекта: сверху падают ноты цвета своей клавиши,
внизу — 25 клавиш (C3–C5) и лента подсветки, как на пианино. Пока пианино не собрано,
играть можно на клавиатуре компьютера, мышью по клавишам на экране или на любой
MIDI-клавиатуре.

## Готовая программа

Python не нужен: программа запускается одним файлом.

- **macOS** — `dist/NotoSvet.app`: двойной щелчок или перетащить в «Программы».
  Чтобы переслать, отправляйте `dist/NotoSvet-macOS.zip`. На чужом Mac при первом запуске
  появится предупреждение о неизвестном разработчике: щёлкните по программе правой кнопкой →
  «Открыть» (на macOS 15 и новее: «Системные настройки» → «Конфиденциальность и безопасность» →
  «Всё равно открыть»). Сборка под Apple Silicon (M1 и новее); для Intel-Mac соберите на Intel-Mac.
- **Windows** — `dist/NotoSvet.exe`, один файл. Собирается только на Windows (см. ниже).

Свои мелодии и результаты готовая программа хранит в папке пользователя:
`~/Library/Application Support/NotoSvet` на macOS, `%APPDATA%\NotoSvet` на Windows.
Если программа упала, причина будет в файле `error.log` в той же папке.

### Как собрать

```bash
pip install pyinstaller
python build.py
```

Скрипт рисует иконку, собирает программу через PyInstaller и сразу запускает её самопроверку
(`NotoSvet --selftest`: уроки, звук, MIDI, импорт мелодии, прохождение урока). Если проверка
не прошла, скрипт сообщит об этом. На macOS получится `.app` и zip-архив,
на Windows — один `.exe`. Собирать нужно на той системе, для которой программа.

## Запуск из исходников

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```

В проекте стоит `pygame-ce` вместо `pygame`. Код тот же (`import pygame`), но у `pygame-ce` есть
сборки для новых Python, например 3.14. Оба пакета сразу ставить нельзя: если `pygame` уже
установлен, удалите его (`pip uninstall pygame`).

## Клавиши

```
  2 3   5 6 7         чёрные: до# ре# фа# соль# ля#   (C#4 … A#4)
 Q W E R T Y U I      белые:  до ре ми фа соль ля си до (C4 … C5)
  S D   G H J         чёрные: до# ре# фа# соль# ля#   (C#3 … A#3)
 Z X C V B N M        белые:  до ре ми фа соль ля си  (C3 … B3)
```

Клавиши считываются по физическому положению, поэтому работают и в русской раскладке.

**Полный экран** — пункт «Полный экран» в главном меню, F11 или Ctrl/Cmd+F на любом экране,
на macOS ещё и зелёная кнопка окна. Программа запоминает режим до следующего запуска.
Окно можно растягивать: картинка масштабируется с сохранением пропорций.

Картинка рисуется в настоящем разрешении экрана. На Retina/HiDPI это вдвое больше
пикселей, а в полном экране — весь экран. Поэтому текст, клавиши и ноты чёткие,
без видимых пикселей.

| Клавиша | Действие |
| --- | --- |
| Пробел | педаль (сустейн) |
| Enter | выбрать / старт / пауза |
| Esc | назад |
| ↑ ↓ ← → | меню и настройки урока |
| Tab | метроном вкл/выкл во время урока |
| F11 или Ctrl/Cmd+F | полный экран |

## Режимы

- **Свободная игра** — каждая клавиша горит своим цветом, от неё вверх уходит полоса.
- **Ожидание** — ноты останавливаются у линии и ждут правильную клавишу. Аккорд засчитывается, когда нажаты все его ноты. Ошибка: клавиша дважды мигает белым и звучит низкий сигнал.
- **Ритм** — ноты идут в темпе под метроном после такта отсчёта. «Отлично» — ±60 мс, «Хорошо» — ±150 мс, иначе «Мимо». Считаются очки и серия, в конце — оценка S/A/B/C.
- **Демонстрация** — программа сама играет мелодию и подсвечивает клавиши.

В каждом режиме выбирается темп (50, 75 или 100 %) и рука, если в мелодии размечены обе
партии. Вторую руку тогда играет программа. Последние 10 результатов по каждой мелодии
сохраняются в `records.json`.

## Редактор мелодии

«Создать мелодию» в главном меню или «Изменить в редакторе» на экране выбора мелодии.

Сетка устроена как бит-сетка в rekordbox. Такты пронумерованы на линейке слева. Сильная доля
отмечена красной линией, каждые 4 такта линия толще. Доли и деления сетки нарисованы тонкими
линиями. Курсор стоит на месте, а сетка движется сквозь него. Время идёт снизу вверх, как ноты
в игре, поэтому каждая нота стоит ровно над своей клавишей.

Ноты можно ставить тремя способами:

- **Мышью.** Щелчок по сетке ставит ноту. Потяните вверх — нота станет длиннее. Ноту можно
  перетащить; за верхний край меняется длина. Правый щелчок удаляет ноту.
- **По шагам.** Нажмите клавишу — нота встанет у курсора, курсор сдвинется на «Длину».
  Аккорд — зажмите несколько клавиш вместе. Ошиблись — Backspace вернёт на шаг назад.
- **Записью.** Enter, такт отсчёта под метроном, потом играйте. Ноты выровняются по сетке,
  если включено «Q» (квантование).

Наверху настраиваются темп (кнопка «Тап» — отстучать темп), сетка (1/4, 1/8, 1/16), длина
новой ноты, рука (авто — ниже «до» первой октавы левая), Q, метроном и ввод клавишами (Tab).
Пробел — играть/стоп, Ctrl/Cmd+Z — отменить, Ctrl/Cmd+S — сохранить, F1 — все клавиши.

Выравнивание по сетке (квантование) работает двумя способами:

- **«Q»** — привязка, как кнопка QUANTIZE в rekordbox. Пока она включена, всё, что ставится
  или двигается, встаёт на линии сетки: ноты от щелчка, перетаскивание, длина, запись и курсор.
  Выключите «Q», чтобы ставить ноты свободно (с точностью 1/48 доли).
- **«Выровнять»** (Ctrl/Cmd+U) ставит на сетку уже стоящие ноты: выбранные, а если ничего
  не выбрано — все. Начало и конец ноты встают на ближайшие линии текущей сетки, нота
  не короче шага сетки. Это для нот, сыгранных без «Q» или пришедших из MIDI-файла.
  Одна отмена возвращает всё как было.

Мелодия сохраняется уроком в папку своих мелодий и сразу появляется в «Учить мелодию».
Встроенную мелодию редактор сохраняет как свою копию.

## Мелодия из своей песни

В редакторе нажмите «Из песни…». Программа покажет песни из папок «Музыка» и «Загрузки»
(с поиском) и даст выбрать файл через «Открыть файл…». Песню можно и просто перетащить в окно.
Открываются MP3, WAV, FLAC, OGG, AIFF, а на macOS ещё M4A/AAC из Apple Music и iTunes.
Защищённые песни из подписки Apple Music не открываются. На Windows M4A откроется,
если установлен ffmpeg.

Дальше появится волна песни. Выделите на ней кусок, где мелодию слышно яснее всего,
например припев; по умолчанию берутся первые 40 секунд после тишины. Кусок можно
прослушать (Пробел) и нажать «Распознать мелодию» (Enter).

Как распознаётся (только numpy, без нейросетей и интернета):

1. Для каждого кадра (93 мс с шагом 11,6 мс) считается заметность каждой высоты от G2 до E6:
   сумма амплитуд её гармоник. Ровный фон аккомпанемента вычитается.
2. Путь мелодии ищется алгоритмом Витерби: скачки высоты и паузы стоят штраф, поэтому
   вибрато и шум не дают «дрожащих» нот.
3. Темп и доли находятся по повторяемости атак, как анализ BPM в диджейских программах.
   Если темп неоднозначен, берётся быстрый: так ритм не теряется. Кнопка «÷2» в редакторе
   переводит в медленный без потерь.
4. Ноты выравниваются по сетке (1/8 или 1/16) и переносятся октавами в 25 клавиш.

Результат открывается в редакторе. Слева видна синяя волна песни, как в rekordbox,
а кнопка «Оригинал» играет песню вместе с нотами — так ошибки сразу слышно.

Лучше всего распознаётся чёткая мелодия: голос или соло-инструмент. На синтетических песнях
с голосом, аккордами, басом и барабанами программа находит 97–100 % нот. В плотном миксе
живой записи ошибок будет больше — поэтому результат и открывается в редакторе.

## Мелодии

Уроки лежат в `lessons/` в формате из плана: один JSON-файл понимают и программа, и прошивка.

```json
{"title": "Ода к радости", "bpm": 90, "notes": [
  {"t": 0, "d": 1, "n": 64, "h": "R", "s": 0}
]}
```

`t` — начало в долях, `d` — длительность в долях, `n` — MIDI-номер 48–72, `h` — рука,
`s` — номер шага (ноты с одним `s` — аккорд). Если `s` не указан, программа проставит его сама.

Свою мелодию проще всего добавить перетаскиванием: бросьте файл `.mid` или `.json` в окно
программы. MIDI сразу превратится в урок: ноты сдвинутся в 25 клавиш и разделятся по рукам.
Урок появится в списке. Кнопка «Открыть папку своих мелодий» на экране выбора мелодии
показывает, где лежат добавленные файлы.

То же из командной строки:

```bash
python tools/converter.py song.mid lessons/song.json
```

## С настоящим пианино

Если найден MIDI-порт с именем «NotoSvet», программа берёт с него нажатия и педаль и
отправляет подсказки на ленту по протоколу из плана: Note On на канале 16, velocity — яркость
(127 — «сейчас», 20 — «следующая»), CC 123 — погасить всё. Любая другая MIDI-клавиатура
тоже подойдёт как источник нажатий. Если MIDI нет, работает клавиатура ПК.

## Устройство

| Файл | Что делает |
| --- | --- |
| `app/trainer.py` | логика режимов: шаги, ожидание, окна «Отлично/Хорошо», очки; без pygame |
| `app/lesson.py` | загрузка уроков JSON |
| `app/synth.py` | звук как в прошивке: 6 гармоник, атака 3 мс, затухание, отпускание 150 мс |
| `app/draw.py` | клавиатура в геометрии пианино, лента из 50 светодиодов, падающие ноты; холст 1280×720 → пиксели экрана |
| `app/display.py` | окно: кадр в разрешении Retina/HiDPI, полный экран, мышь в координатах 1280×720 |
| `app/settings.py` | настройки между запусками (полный экран) |
| `app/game.py` | экраны и ввод: клавиатура ПК, мышь, MIDI, перетаскивание файлов |
| `app/editor.py` | редактор: сетка, ввод по шагам, запись с квантованием, отмена, сохранение; без pygame |
| `app/editor_view.py` | экран редактора: бит-сетка, мышь, панель инструментов |
| `app/transcribe.py` | распознавание: песня → мелодия, темп, сетка; только numpy |
| `app/audio.py` | открыть песню (MP3, WAV, FLAC, OGG, AIFF, M4A через afconvert/ffmpeg) |
| `app/library.py` | поиск песен в «Музыке» и «Загрузках», системный выбор файла |
| `app/import_view.py` | экраны «Мелодия из песни»: библиотека, волна и фрагмент, распознавание |
| `app/converter.py` | MIDI → урок (конвертер из плана) и добавление своих мелодий |
| `app/paths.py` | где лежат уроки и результаты — из исходников и в готовой программе |
| `app/icon.py` | иконка программы (рисуется кодом) |
| `app/selftest.py` | самопроверка `--selftest` |
| `build.py` | сборка готовой программы |
| `app/midi_io.py` | USB-MIDI: нажатия с пианино, подсказки на пианино |
| `app/config.py` | диапазон, цветовой код нот, раскладка клавиш |

Тесты: `python -m pytest`.
